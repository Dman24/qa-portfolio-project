# Restful-Booker Manual API Testing
## Project Overview
This project focuses on manual api testing of the Restful-booker API using Postman

The objective of this project is to verify API functionality, validate request and response data, check status codes, and identify potential issues through positive and negative testing scenarios.

**Base URL:** https://restful-booker.herokuapp.com

## Test Case Documentation

Detailed test cases and test results are documented in Google Sheets.

## API Testing Coverage

The following HTTP methods and functionalities were tested:

- GET - Retrieve all bookings and specific booking details
- POST - Create new bookings and generate authentication tokens
- PUT - Update existing booking details
- PATCH - Partially update booking details
- DELTE - Delete existing bookings
